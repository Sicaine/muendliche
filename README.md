# Bayerische Jägerprüfung – Lernhilfe Mündliche Prüfung

Interaktive Lernhilfe für die mündliche Jägerprüfung in Bayern, basierend auf echten Gedächtnisprotokollen von Prüfungen 2023–2025.

## Features

- **6 Sachgebiete** entsprechend dem Prüfungsaufbau
- **Lernmodus**: Alle Fragen und Antworten übersichtlich, einzeln aufklappbar
- **Quiz-Modus**: Eine Frage auf einmal, Antwort auf Klick aufdecken
- **Shuffle**: Fragen zufällig mischen
- **KI-Antworten**: Wo keine Antwort in den Protokollen stand, wurden Antworten KI-gestützt ergänzt und deutlich markiert – bitte mit Fachliteratur verifizieren (z.B. Heintges)

## Sachgebiete

1. Waffen und Waffenrecht
2. Wildbiologie
3. Jagdrecht
4. Jagdpraxis und Wildkrankheiten
5. Jagdhunde
6. Naturschutz und Landbau

## Quellen

Die Fragen basieren auf Gedächtnisprotokollen folgender Prüfungen:

- Ebersberg, 22.05.2024
- März 2023
- Simon/Rosenheim, 21.05.2025
- Q2 2024
- Protokolle Florian, Max, Tom (Ebersberg 2025)

## Hinweis

Diese Lernhilfe ersetzt keine offizielle Prüfungsvorbereitung. Für die vollständige Vorbereitung empfehlen sich:
- Heintges-Lernhefte
- App „Waidwissen"
- Kursmaterial deines Jagdverbands
